Title: AI Refactoring Tutorial 3 – Introducing Dependency Injection in a Python Module

Step 1: Start with tightly coupled code.
Example:
class EmailService:
    def send(self, to, subject, body):
        print(f"Sending email to {to}")

class UserManager:
    def __init__(self):
        self.email_service = EmailService()
    
    def notify_user(self, user_email):
        self.email_service.send(user_email, "Welcome", "Thanks for signing up!")

Step 2: Ask the AI:  
“Refactor this module to support dependency injection for easier testing.”

Step 3: Examine the AI-generated result:
class EmailService:
    def send(self, to, subject, body):
        print(f"Sending email to {to}")

class UserManager:
    def __init__(self, email_service: EmailService):
        self.email_service = email_service
    
    def notify_user(self, user_email):
        self.email_service.send(user_email, "Welcome", "Thanks for signing up!")

Step 4: Prompt the AI again:  
“Write a unit test for UserManager using a mock EmailService.”

Step 5: Test the new code and validate flexibility.

Goal: Teach the value of decoupling for testing, scaling, and maintainability using automated refactoring.
